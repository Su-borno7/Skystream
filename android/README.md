# Skystream for Android

This is the Android app of **Skystream**, based on the open-source
[CloudStream](https://github.com/recloudstream/cloudstream) app (GPL-3.0).
It is a feature-identical fork rebranded as Skystream — the CloudStream extension
repositories and `.cs3` plugins work unchanged.

See the [repository root README](../README.md) for builds, downloads and documentation.

Upstream changes are periodically merged into this fork. Modifications made by the
Skystream project are listed in `NOTICE.md` at the repository root.
